# 布典人生 · 面料管理协同平台 v5.0

以面料数字资产为底座，打通样品管理、AI展示、销售服务与客户转化。纯前端静态演示系统（React + Vite + Tailwind），无需后端，数据存于浏览器 localStorage。

## 在线体验

部署后地址形如：`https://<用户名>.github.io/budian-platform/`

- **管理端**：`/#/admin` —— 工作台 / 面料库 / 样料库存 / 电子册 / 客户管理 / 客户选样 / B2B询价单 / 标签体系 / AI换布演示
- **用户端**：`/#/shop` —— 首页 / 面料库 / 面料详情 / B2B商城（询价篮）/ 我的选样
- **电子册分享页**：`/#/ebook/E001`（打印可导出PDF）
- 顶部可随时互切管理端/用户端；右上角「重置演示数据」一键恢复初始状态

## 超越参考原型的功能点

1. **六维筛选真实可用**（品类/风格/场景/性能/库存/颜色，带计数）
2. **样料库存全流程操作**：入库/出库/借用/领用/转借/归还，写流水、联动预警与工作台
3. **客户选样闭环**：用户端提交 → 管理端队列 → 状态流转 → 跟进记录时间线
4. **B2B商城询价闭环**：询价篮 → 提交 → 管理端实时接收，价格按客户档位（A/B/C类）折算
5. **AI选样助手**：本地规则引擎解析风格/场景/预算/性能，秒级匹配推荐面料
6. **AI换布演示**：Canvas 合成，保留场景明暗、映射面料色彩纹理，滑块对比，可导出PNG
7. **电子册生成与分享**：勾选面料生成册子 → 分享链接 → 在线翻阅 → 打印导出PDF

## 本地运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建静态文件到 dist/
npm run preview  # 预览构建产物
```

## 部署到任意静态托管

`dist/` 为纯静态文件（相对路径，可放在任意子路径）：

- **GitHub Pages**：见下方
- **Netlify / Vercel**：拖拽 `dist/` 或指向构建命令 `npm run build`、产物目录 `dist`
- **aiforce 等平台**：直接上传 `dist/` 内全部文件

### GitHub Pages 手动部署

```bash
npm run build
npx gh-pages -d dist        # 或：把 dist 内容推送到 gh-pages 分支
```

仓库设置中开启 Pages（来源 gh-pages 分支）即可。
